# AKA.SO Userscript

웹사이트 우측 하단의 AKA.SO 아이콘으로 현재 페이지나 직접 입력한 URL을 단축합니다. 기존 Chrome 확장과 별도로 동작하는 Tampermonkey용 스크립트입니다.

## 설치

1. 브라우저에 [Tampermonkey](https://www.tampermonkey.net/)를 설치합니다.
2. Tampermonkey 메뉴에서 **새 스크립트 만들기**를 선택합니다.
3. 기본 내용을 지우고 `akaso.user.js` 전체 내용을 붙여넣습니다.
4. 저장한 뒤 사용하려는 웹사이트를 새로고침합니다.

Tampermonkey가 userscript 실행을 위한 브라우저 설정을 요청하면 안내에 따라 활성화하세요. HTTP/HTTPS 웹사이트의 최상위 페이지에만 실행하며, 브라우저 내부 페이지와 확장 스토어 등 스크립트 실행이 제한된 페이지에서는 표시되지 않습니다.

`icon.png`의 원본 이미지를 스크립트에 포함했으므로 별도 이미지 파일이나 이미지 서버는 필요하지 않습니다.
아이콘 버튼은 44×44px의 원형으로 표시합니다.

Popover API를 지원하는 브라우저에서는 아이콘과 패널을 브라우저의 최상위 표시 영역에 올립니다. 사이트의 팝업, 모달, 전체 화면 전환과 페이지 요소 교체 후에도 표시 위치를 복구합니다. 미지원 브라우저에서는 최대 `z-index`의 고정 요소로 표시합니다.
유튜브처럼 Trusted Types를 적용한 사이트에서도 화면을 만들 수 있도록 `innerHTML`을 사용하지 않고 DOM 요소를 직접 생성합니다.

## 사용

1. 우측 하단 아이콘을 누르고 **설정**을 엽니다.
2. `Bearer` 접두어 없이 AKA.SO API 토큰을 입력합니다.
3. 기본 상태 코드(301, 302, 307, 308 중 하나, 초기값 302)를 선택하고 저장합니다.
4. **링크 생성으로 돌아가기**를 누르고 URL과 선택적인 링크 비밀번호를 입력합니다.
5. **URL 줄이기**를 누릅니다. 결과를 복사하거나 새 탭에서 열 수 있습니다.

패널과 설정을 열 때 입력란에 자동으로 포커스를 주지 않습니다. 터치 기기에서는 입력 글자 크기를 16px로 표시합니다.

복사 버튼은 HTTPS 페이지에서 브라우저의 클립보드 API를 먼저 호출하고, 사용할 수 없거나 거부되면 Tampermonkey 복사 API를 시도합니다. 복사 완료를 확인한 경우에만 성공 메시지를 표시합니다. 아이폰에서 두 방식 모두 사용할 수 없으면 단축 URL을 길게 눌러 직접 복사하세요.

현재 페이지 URL은 아이콘을 열 때 입력됩니다. 주소가 바뀌었다면 **현재 페이지 URL 가져오기**를 누르세요. 설정은 Chrome 확장의 설정과 공유하지 않으므로 토큰을 별도로 입력해야 합니다.

### 아이콘 숨기기와 복구

- 마우스로 아이콘을 오른쪽으로 끌거나 터치로 오른쪽으로 스와이프하면 숨겨집니다.
- 오른쪽으로 32px 이상 이동한 경우 숨깁니다. 단순 클릭, 왼쪽 드래그, 세로 드래그는 숨기지 않습니다.
- 숨기기는 현재 페이지에만 적용됩니다. 새로고침하면 다시 표시됩니다.
- 새로고침 없이 복구하려면 Tampermonkey 메뉴에서 **AKA.SO 아이콘 다시 표시**를 선택합니다.
- 메뉴의 **AKA.SO 설정**으로 설정을 바로 열거나 **AKA.SO 아이콘 숨기기**로 숨길 수도 있습니다.

## API와 저장

`POST https://aka.so/api/links`로 다음 multipart 폼 필드를 전송합니다.

| 필드 | 값 |
| --- | --- |
| `type` | `link` |
| `location_url` | 목적지 URL |
| `domain_id` | `0` |
| `http_status_code` | 저장한 상태 코드. 설정이 없으면 302 |
| `password` | 입력한 비밀번호. 비어 있으면 생략 |

`is_bulk`는 전송하지 않습니다. 인증은 `Authorization: Bearer {API_TOKEN}`이며, 쿠키를 전송하지 않습니다. 요청 제한 시간은 20초이고 자동으로 재시도하지 않습니다. API 요청은 Tampermonkey의 `GM_xmlhttpRequest`로 처리하며 연결 허용 대상은 `aka.so`입니다.

응답의 `domain_id`가 `0`이면 `url` 또는 `link_id`로 `https://aka.so/aa11` 형태의 단축 주소를 만듭니다. 이전 응답과 호환되도록 `domain_id`가 생략되면 기본 도메인으로 처리합니다.

토큰과 기본 상태 코드는 Tampermonkey의 스크립트 전용 저장소에 보관하며 사이트의 `localStorage`를 사용하지 않습니다. 입력 패널은 닫힌 Shadow DOM을 사용합니다. 링크 비밀번호는 저장하지 않으며 생성 성공 또는 패널 닫기 시 입력란에서 지웁니다. 목적지 URL, 인증 토큰, 입력한 링크 비밀번호는 생성 요청 시 AKA.SO에 전달합니다.

## 테스트

저장소 루트에서 Node.js 20 이상으로 실행합니다.

```bash
node --test userscript/tests/api.test.mjs
```

모의 응답으로 API 요청 필드, 인증, 결과 주소 변환, 오류 처리와 클립보드 복사의 완료·실패 처리를 확인합니다. 실제 링크를 생성하지 않습니다.

참고: [Tampermonkey API 문서](https://www.tampermonkey.net/documentation.php?ext=d2&q=GM_xmlhttpRequest)
